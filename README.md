# Saritha — Prism-inspired Portfolio

A responsive React + Vite portfolio recreated from the reference screenshots.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Personalize before publishing

Open `src/App.jsx` and update the `profile` object:
- `email`: your real email address
- `linkedin`: your LinkedIn profile URL
- `github`: your GitHub profile URL

Also update `education` with your exact college name, qualification dates and certificates. Project links are currently `#`; replace them with the relevant GitHub/live demo URLs when ready.

## Build

```bash
npm run build
npm run preview
```

This is an independent recreation based on the screenshots supplied by the portfolio owner. It is not the original Lovable source code.
